15 – Recursion

  1. Explain the difference between a recursive and a non-recursive function
    1. Self reference makes a function recursive. Functions that do not call themselves are non-recursive.
    1. A recursive function solves only one problem. A recursive call is just saying “To do this task, use a copy of the instructions you are reading now to solve a slightly smaller version of the problem.”
  1. Explain the purpose of the base and recursive cases of a recursive function
    1. Base Case: Describes the scenario where the problem is small enough to be solved directly without further recursion. It's the stopping condition.
    1. Recursive Case: Describes how the problem can be divided into smaller instances of the same problem and how the function calls itself with modified input parameters to solve these smaller instances.
  1. Identify the base and recursive cases of a recursive function
  1. Understand how recursive formulations for algorithms are derived
    1. Deriving recursive formulations for algorithms often involves identifying a problem that can be broken down into smaller, similar sub-problems. The process generally follows these steps:
      1. Identify the Base Case:
        1. Determine the smallest instance or simplest scenario of the problem that can be solved directly without further recursion. This is known as the base case.
        1. The base case serves as the stopping condition for the recursion.
      1. Define the Recursive Case:
        1. Express the problem in terms of smaller instances of the same problem.
        1. Formulate the solution to the current problem in terms of solutions to smaller instances of the problem.
        1. This is the recursive case.
      1. Combine Results:
        1. Define how the solutions to the smaller instances can be combined to solve the overall problem.
      1. Establish Recursion Termination:
        1. Ensure that the recursion eventually reaches the base case to avoid infinite recursion.
        1. Each recursive call should move towards the base case.
      1. Implement the Algorithm:
        1. Translate the recursive formulation into actual code
  1. Explain recursion in terms of the delegation metaphor
    1. In the context of recursion, the delegation metaphor involves breaking down a complex problem into simpler, similar sub-problems and delegating the solution of each sub-problem to a recursive call. The metaphor is akin to asking a smaller version of yourself (the recursive call) to handle part of the task.

  1. Explain the divide and conquer approach to problem solving
    1. The divide and conquer approach involves breaking a problem into smaller sub-problems, solving each sub-problem recursively, and then combining the solutions.
  1. Describe, in plain English, the algorithm for merging two sorted sequences into a single sorted sequence
    1. Initialize Pointers: Start pointers at the beginning of both sequences.
    1. Compare Elements: Compare the elements at the pointers. Append the smaller element to the merged sequence and move the pointer of the appended element forward.
    1. Handle Remaining Elements: If one sequence is exhausted before the other, append the remaining elements of the non-exhausted sequence to the merged sequence.
  1. Describe, in plain English, the merge sort algorithm, and identify the divide and conquer portions of the algorithm
    1. Divide: Split the list into two halves.
    1. Conquer: Recursively sort each half.
    1. Combine: Merge the two sorted halves into a single sorted list.
  1. Describe, in plain English, the partition algorithm used by quick sort
    1. Pivot Selection: Choose a pivot element.
    1. Partitioning: Rearrange elements so that all elements less than the pivot come before it and all elements greater than the pivot come after it.
    1. Final Position: The pivot is now in its correct position.
  1. Describe, in plain English, the quick sort algorithm, and identify the divide and conquer portions of the algorithm
    1. Divide: Choose a pivot and partition the array into two sub-arrays, one with elements less than the pivot and one with elements greater than the pivot.
    1. Conquer: Recursively apply quick sort to the sub-arrays.
    1. Combine: The array is already sorted after the recursive calls and partitioning.
  1. Describe, in general terms, the relative strengths and weaknesses of insertion sort, merge sort, and quick sort
    1. Insertion Sort:
      1. Strengths: Simple, efficient for small or nearly sorted data.
      1. Weaknesses: Inefficient for large or random data sets (O(n2)).
    1. Merge Sort:
      1. Strengths: Efficient (O(nlogn)), stable, good for large data sets.
      1. Weaknesses: Requires additional space for merging.
    1. Quick Sort:
      1. Strengths: Very efficient on average (O(nlogn)), sorts in place.
      1. Weaknesses: Worst-case performance (O(n2)) if pivot selection is poor.

19 – Computer Architecture

  1. Describe the differences between a fixed function and a von Neumann architecture computer
    1. Fixed Function: Specialized for specific tasks; limited functionality.
    1. Von Neumann Architecture: General-purpose design; consists of CPU, memory, and I/O; allows for flexibility in programming.
  1. Provide definitions for bit and byte
    1. Bit: Binary digit, 0 or 1.
    1. Byte: Group of 8 bits; represents a character or piece of data.
  1. Describe the organization of main memory in a computer
    1. RAM (Random Access Memory): Stores actively used data and instructions.
    1. Addressable Units: Typically organized in bytes.
    1. Quick Access: Allows the CPU to rapidly retrieve and store data.
  1. Explain what a memory address is, and what it is used for
    1. Unique Identifier: Specifies a location in the computer's memory.
    1. Access and Retrieval: Used by the CPU to fetch data from specific memory locations.
    1. Each byte in the sequence has a numeric address that is used by the computer to access the data stored in the byte very quickly. This address is not actually stored in memory; it is implicit in the design of the memory circuitry. The address of the first byte in the sequence is 0, the second is 1, the third is 2, and so on; think of the address of a byte in memory as its offset from the start of the sequence (the first byte in the sequence is offset 0 from the start of the sequence). Viewed in this way, the main memory of a computer is a very large one-dimensional sequence of bytes.
  1. Describe the basic function of the central processing unit, arithmetic logic unit, and control unit of a computer
    1. Central Processing Unit (CPU): Executes instructions; the core processing unit.
    1. Arithmetic Logic Unit (ALU): Performs arithmetic and logical operations.
    1. Control Unit: Manages instruction execution and component coordination.
  1. Explain the purpose of the instruction pointer register and instruction register
    1. Instruction Pointer Register: Holds the memory address of the next instruction.
    1. Instruction Register: Stores the current instruction being executed.
  1. Describe the steps of the machine cycle algorithm
    1. Fetch: Retrieve the next instruction from memory.
    1. Decode: Interpret the instruction to determine the operation.
    1. Execute: Carry out the operation specified by the instruction.
    1. Store: Save the result in memory if needed.
