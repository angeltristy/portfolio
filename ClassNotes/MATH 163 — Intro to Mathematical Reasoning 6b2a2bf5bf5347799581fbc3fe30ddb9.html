Sets and Functions I

  • Element: A member of a set.
  • Natural Numbers (N): The set of natural numbers is the set {0, 1, 2, 3…}
  • Natural Numbers (N+): The set of natural numbers without zero is {1, 2, 3…}
  • Rational numbers (R): Rational numbers are elements of this set:
    • R means the real numbers. R^2 means the set of pairs, (a, b), where a and b are in set R.
  • Set builder notation: See above
  • Integers (Z): The integers are the elements of the set {..., -3, -2, -1, 0, 1, 2, 3…}
  • Real Numbers: Numbers that appear on the number line.
  • Element: When X is a set and x is a member of X, we say that x is an element of X.
  • Subset (⊆, ⊇): When every element of X is also an element of Y we say X is a subset of Y.
  • Superset: When every element of X is also an element of Y we say Y is a superset of X.
  • Proper subset (⊂, ⊃): When X is a subset of Y and X ̸= Y we say X is a proper subset of Y.
  • Union of A and B (∪): The set of elements that are in A or B.
    • X ∪ Y = {x | x ∈ X or x ∈ Y }.
  • Intersection of A and B (∩): The set of elements that are in both A and B.
    • X ∩ Y = {x | x ∈ X and x ∈ Y }
  • Cartesian product of A and B (A X B): The set of all ordered pairs whose first element is from X and second element is from Y.
    • X × Y = {(x, y) | x ∈ X and y ∈ Y }
  • X\Y: Given sets X and Y, we define X\Y to be the set that contains the elements in X that are not elements of Y.

Sets and Functions II

  • Function: Let A,B and f be sets. We say f is a function from A to B when f is
a subset of A × B in which each element of A appears as the first entry of an ordered pair exactly once.
  • Domain / Codomain: When f is a function from A to B we write f : A → B. We say that A is the domain of f and that B is the codomain of f.
  • f : A -> B: When f is a function from A to B we write f : A → B.
  • Image / Preimage: Let A and B be sets and let f be a function from A to B.
For (a, b) ∈ f we say b is the image of a and a is a preimage of b. When b is the image of a we write f(a) = b.
  • f^-1(b): Let A and B be sets, let f be a function from A to B and let b be an element of B. The preimage of b is the set {a ∈ A | f(a) = b}. We denote this set as f^-1(b).
  • Range: Let A and B be sets and let f be a function from A to B. The range of
f, denoted range(f), is the set of elements of B that are the image of some element of A.
  • Injection: Let A and B be sets and let f be a function from A to B. We say f is an injection when each element of the domain has a unique image. When f is an injection we say that f is injective or a one-to-one function. Every x has at most one y.
  • Surjection: Let A and B be sets and let f be a function from A to B. We say f is a surjection when range(f) = B. When f is a surjection we say that f is surjective or an onto function. Every y has at least one x.
  • Bijection: Let A and B be sets and let f be a function from A to B. We say f is a bijection when f is both an injection and a surjection. When f is an bijection we say that f is bijective.
    • Every bijective function must have an inverse.
  • Operation: Let A be a set. An operation on A is a function f : A × A → A.
  • Inverse: Let A and B be sets, let f be a bijective function from A to B and let g be a function from B to A. We say g is the inverse of f when (g ◦ f) (a) = a for every a ∈ A. When g is the inverse of f we may label g as f^(−1).

Relations I

  • Reflexive: Yes, each element of the form (x, x) appears.
  • Antireflexive: Yes, if an element of the form (x, x) doesn't appear.
  • Symmetric: Yes, if (x, y) appears with x ̸= y, then (y, x) does appear.
  • Antisymmetric: Yes, if (x, y) appears with x ̸= y, then (y, x) does not appear.
  • Transitive: Yes, if (x, y) and (y, z) appear, then (x, z) appears.
  • Powerset: Let U be a set. The set of all subsets of U is called the power set of U. We denote the power set of U as 2^U.
  • Partial order: We say R is a partial order when R is reflexive, antisymmetric and transitive.
  • Graph: Let V be a set and let E be a relation on V . We say E is a graph when E is symmetric and antireflexive.
  • X divides Y: Let x and y be integers. We say x divides y when there exists k ∈ Z so that xk = y. When x divides y we say that y is a multiple of x.

Relations II

Introduction to Formal Logic

  • Mathematical proof: A finite sequence of formal mathematical statements such that each statement either:
    • is an axiom or assumption, or
    • follows by formal rules of logical deduction from previous statements in the sequence.
  • Mathematical statement: a sentence that is either true or false.
  • Truth value, denoted T(P) = 0 or 1: If P is true, we say P has truth value 1, and we write T(P) = 1. If P is false, we say P has truth value 0 and we write T(P) = 0.
  • Truth table: Table with 1’s and 0’s to indicate truth or false based on the conditions for each column.
  • Logically equivalent: When the truth tables are the same for two different statements.
  • not P, denoted -P: We have T(¬P) = 1 when T(P) = 0, and we have T(¬P) = 0 when T(P) = 1.
  • P and Q, denoted P ∧ Q: We have T(P ∧ Q) = 1 when T(P) = 1 and T(Q) = 1. We have T(P ∧ Q) = 0 otherwise.
  • P or Q, denoted P V Q: We have T(P ∨ Q) = 0 when T(P) = 0 and T(Q) = 0. We have T(P ∨ Q) = 1 otherwise.
  • P implies Q, denoted P > Q: When one truth implies another.
  • Hypothesis and Conclusion:: We call P the hypothesis of the implication and we call Q the conclusion of the implication.
  • Converse: Let P and Q be statements. The statement Q ⇒ P is called the converse of the implication P ⇒ Q. For ex., if n = prime, then n = 54 is the converse.
  • Contrapositive: Let P and Q be statements. The statements P ⇒ Q and ¬Q ⇒ ¬P are logically equivalent. The statement ¬Q ⇒ ¬P is called the contrapositive of P ⇒ Q. For ex., if n /= prime, then n /= 54.

  • Mathematical formula: A mathematical formula over X is a statement that has a truth value for each choice of x ∈ X. We denote a mathematical formula with the notation P(x).

Set Cardinality II

  • Finite set: Let A be a set. We say A is finite when there exists k ∈ N so that |A| = k.
  • Infinite set: When A is not finite we say A is infinite.
  • |A| <= |B|: Let A and B be sets. We say that |A| ≤ |B| if there exists an injection f: A → B.
  • |A| < |B|: Furthermore, if |A| ≤ |B| and there does not exist a surjection from A to B, then we write |A| < |B|.
  • Countable: Given an infinite set S, we say that S is countable if |S| = |N|. The same amount of elements in the set of natural numbers.
  • Uncountable: Otherwise, we say that S is uncountable.
