Systems of Equations

1.1 Systems of Equations - Geometric

  • A system is just one or more linear equations that can be solved by finding the variable value that makes every equation true.
  • You can find solutions by graphing

1.2 Systems of Equations - Algebraic Procedures

  • A system of linear equations is a list of equations, where aij and bj are real numbers.
  • aij represents the ith row and jth column element of a matrix A, where A is a matrix of coefficients.
  • System of equations with m equations and m variables.
  • Scalars = any real number
  • A system of equations is homogeneous if every equation = 0.
  • Solution set are the values for x1 … xn which solves all equations.
  • System of linear equations is consistent if there is at least 1 solution.
  • Inconsistent if no solution.
  • 2 systems are equivalent if they have the same solution set.
  • Elementary Operations
    1. Interchange the order equations are listed.
    1. Multiply any equation by a nonzero number
    1. Add a multiple of one equation to another equation.
  • Gaussian Elimination
    • First represent system with an augmented matrix.
      • A matrix is a rectangle array of numbers.
      • Size represented by m x n, where m = rows, n = col.
      • To create augmented matrix, create a coefficient matrix and a constant matrix.
      • Coefficients from 1 equation create 1 row of the augmented matrix.
  • Elementary Row Operations
    1. Switch 2 rows.
      • A -> B
      • ri<->rj
    1. Multiply a row by a nonzero number, k.
      • A -> B
      • kri
    1. Add a multiple of one row to another row.
      • A -> B
      • kri + rj
  • Augmented Matrix is row Form if:
    1. All nonzero rows are above zero rows.
    1. Each leading entry of a row is in a column to the right of the leading entries of any row above m.
    1. Each leading entry of a row is equal to 1.
  • In reduced row form if:
    1. All entries in a column above and below a leading entry are zero.
  • Leading entry is first nonzero entry.
  • Gaussian Elimination - row echelon form
  • Gauss-Jordan Elimination - reduced row echelon form.
  • Row Reducing a Matrix
  • Rank and Homogeneous Systems
    • A system is homogeneous if every equation = 0.
    • The trivial solution is 0 being the solution.
    • We want to find nontrivial solution.
    • Suppose we have a homogeneous system of m equations, with n variables and suppose that n > m. Equations with more variables than equations always have a nontrivial solution.
    • Linear combinations are obtained by multiplying matrices by scalars and adding them together.
    • A linear combo of the basic solutions to a homogeneous system is a solution to the system.
    • To find rank, use row reduction. The rank is the number of non-zero rows.
    • The system has a unique solution if r = n.
    • The system has infinite solutions if r < n.

2.3 The Transpose

Definition 2.27: The Transpose of a Matrix
  • Denoted by AT
  • Flips the I and j.
  • The (I, j)-entry of A becomes the (j, i)-entry.
Definition 2.30: Symmetric and Skew Symmetric
  • An nxn matrix A is said to be symmetric if A=AT
  • It is said to be skew symmetric if A = -AT

2.4 The Identity Matrix and Matrix Inverses

Definition of an Invertible Matrix
  • An invertible matrix (aka non-singular matrix) is a square matrix that has an inverse.
  • A is invertible if there is another matrix B of the same size such that AB = BA = I, where I is the identity matrix.
  • Inverse denoted as A1
  • B is a witness that A is invertible

Non-invertible 2x2 matrix

2.5 Finding the Inverse of a Matrix

Algorithm 2.39: Matrix Inversion
  • Suppose A is an nxn matrix.
  • To find A1 if it exists, form the augmented nx2n matrix.
    • [A|I]
  • If possible, do row operations until you obtain [I|B] where B = A1.

2.6 Elementary Matrices

  • Any elementary matrix, which we often denote E, is obtained from applying ONE row operation to the identity matrix of the same size.
  • Those which involve switching rows are called permutation matrices.
  • Every elementary matrix is invertible and its inverse is also an elementary matrix.
  • Find inverse by doing the reverse row operations on I.
  • Matrix A is invertible if it can be obtained by multiplying elementary matrices.

2.7 Two Theorems on Matrix Inverses

Theorem 2.63: Unique Inverse of a Matrix
  • Suppose A and B are square matrices.
  • Such that AB = I where I = identity matrix.
  • Then it follows that BA = I.
  • Thus, both A and B are invertible and B=A1 and A = B1.
Theorem 2.64: The RREF of an Invertible Matrix
  • For any matrix A, the following conditions are equivalent:
    • A is invertible
    • The RREF of A is an identity matrix

2.8 LU Factorization

Triangle Matrices
  • Upper triangle matrix if every entry below the main diagonal is 0.
  • Lower triangle matrix if every entry above the main diagonal is 0.
  • Triangle matrix if it is either upper or lower.
LU Factorization
  • Factor A as a product of lower triangle matrix and upper triangle matrix, where L has ones along the diagonal.
Direct Computation
  • Matrices that can be put into RREF without switching rows, can be LU factored.
LU Factorization via the Multiplier Method
  • Use elementary operations to create upper triangle, not the multipliers and corresponding multipliers to obtain zero is the equal value in lower triangle.

Determinants

3.1 Determinants Basic Techniques and Properties

Definition 3.1: Determinant of a 1x1 Matrix
  • Let A = [a]
  • Then det(A) = a
Definition 3.2: Determinant of a 2x2 Matrix
  • Let A = [ a b, c d]
  • Then det(A)= ad - cb
Definition 3.4: The ijth Minor of a Matrix
  • Let A be a 3x3 matrix.
  • The ijth minor, denoted a minor(A)ij, if the dot of the 2x2 matrix which results from deleting the ith row and jth column.
Definition 3.6: The ijth Cofactor of a Matrix
  • Suppose A is an nxn matrix.
  • The ijth cofactor, denoted by cof(A)ij is defined to be:
    • cof(A)ij = (-1)i+jminor(A)ij
Definition 3.8: Determinant of a 3x3 Matrix
  • Let A be a 3x3 matrix.
  • We calculate det(A) by picking a row (or column) and taking the product of each entry in that row (or column) with its cofactor and adding those products together.
  • Known as expanding along the ith row (or column) as is given by:
    • det(A) = di1cof(A)i1 + ai2cof(A)i2 + ai3cof(A)i3
  • Known as Laplace Expansion or Cofactor Expansion.
Finding Determinants using Row Operations
  • Use row operations to a column or row, making the every one but the first number = 0.
  • Use Laplace.

4.1 Vectors in Rn: Geometry

  • You can use arrows to represent vectors.
  • They have both magnitude (measured by the length of the area) and direction (orientation of the arrow).
  • If vectors have same magnitude and direction, they're equal.
The Geometry of Scalar Multiplication
  • If K is a positive real number, then K v(arrow) that points in same direction and length is k times the length of r(arrow).
  • If k is a negative number, the direction is opposite, while length is k times the length of v(arrow).
The Geometry of Vector Addition
  • Slide v(arrow) so that the tail of v(arrow) is on the point of u(arrow).
  • Draw the arrow which goes from the tail of u(arrow) to the point of v(arrow). This arrow represent u(arrow) + v(arrow).
