CMPT 280 FINAL EXAM STUDY CHECKLIST

BIG-O / TIMING ANALYSIS

  • Simplify time complexity expressions (e.g., 5n^2 + 3n + 10 → O(n^2))
  • Identify dominant term
  • Compare growth rates (log n, n, n log n, n^2, etc.)
  • Analyze loops:
    • single loop → O(n)
    • nested loops → O(n^2)
    • triangular loops → O(n^2)
    • halving/doubling loops → O(log n)
  • Understand Big-O vs Big-Theta

LISTS AND ITERATION

  • Understand singly vs doubly linked lists
  • Know how to insert:
    • beginning
    • middle
    • end
  • Understand cursor vs iterator
  • Know basic iterator operations:
    • goFirst, goForth, itemExists, before, after

ABSTRACT DATA TYPES (ADTs)

  • Define what an ADT is
  • Know the components:
    • name
    • sets
    • signatures
    • preconditions
    • semantics

ARRAYED BINARY TREES

  • Know index relationships:
    • left child = 2i
    • right child = 2i + 1
    • parent = i / 2
  • Understand when array representation is efficient (complete trees)
  • Know basic insert and delete rules

HEAPS (HIGH PRIORITY)

  • Define heap:
    • complete binary tree
    • heap property (parent ≥ children for max-heap)
  • Perform:
    • insertion (bubble up)
    • deletion (bubble down)
  • Identify and fix heap violations
  • Know time complexity: O(log n) for insert/delete

AVL TREES (VERY HIGH PRIORITY)

  • Define AVL tree (self-balancing BST)
  • Compute balance factor: height(left) - height(right)
  • Know valid balance factors: -1, 0, +1
  • Detect imbalance (|BF| > 1)
  • Know rotations:
    • LL (single right)
    • RR (single left)
    • LR (left then right)
    • RL (right then left)
  • Perform AVL insertion step-by-step
  • Perform AVL deletion and rebalancing

m-ARY TREES

  • Understand structure (nodes with up to m children)
  • Know representations:
    • array of children
    • linked list of children
  • Understand recursive traversal

2-3 TREES

  • Understand node structure (2-node and 3-node)
  • Perform insertion
  • Handle node splitting
  • Maintain balanced structure

HASH TABLES

  • Understand hashing concept
  • Define collision
  • Handle collisions:
    • chaining
    • linear probing (and other probing methods if covered)

k-D TREES

  • Understand multi-dimensional tree concept
  • Know splitting alternates by dimension (x, y, etc.)
  • Understand median-based construction
  • General conceptual understanding

GRAPHS (VERY HIGH PRIORITY)

  • Basics:
    • vertices and edges
    • directed vs undirected graphs
  • Representations:
    • adjacency matrix
    • adjacency list
  • Traversals:
    • BFS (breadth-first search)
    • DFS (depth-first search)
  • Algorithms:
    • Dijkstra:
      • finds shortest paths from a source vertex
    • Kruskal:
      • finds a minimum spanning tree (MST)
      • uses disjoint sets

SORTING

  • General understanding of sorting algorithms
  • Understand concept of linear-time sorting

TESTING (LIGHT)

  • Understand regression testing
  • Know steps of creating a test case:
    • define scenario
    • set up state
    • determine expected result
    • run and verify

FINAL SELF-CHECK

  • Can analyze time complexity of code
  • Can perform heap insert/delete correctly
  • Can perform AVL insertions and identify correct rotations
  • Can explain and apply graph algorithms (Dijkstra and Kruskal)
  • Can recognize and explain differences between data structures
