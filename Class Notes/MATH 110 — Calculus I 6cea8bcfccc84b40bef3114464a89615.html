Functions and Graphs

Section 1.1: Review of Functions

  • Functions: A rule that assigns each input value to exactly one output value
  • Domain: the set of input values
  • Range: the set of output values
  • Independent variable: x: in which we substitute input values from the domain
  • Dependent variable: y: which gives us the corresponding output values from the range
  • Function notation: we write y = f(x)
  • A function can be represented as a formula, a table of values, and a graph.
  • A graph represents a function only if it passes a rule called the vertical line test. Every vertical line that may be drawn on a graph should intersect one line. If any vertical line intersects a graph more than once, it is not a function.
  • You can find the zeros and y intercept of a function by setting the opposite value to zero and solving for the variable.

Function composition

  • By combining functions f and g using operations, we can make new functions. We can also create new functions using an operation called function composition.

Symmetry of Functions

  • If f(x) = f(-x) for all x in the domain, the function is called even.
    • An even function symmetric about the y-axis.
  • If f(-x) - f(x) for all x in the domain, the function is called odd.
    • An odd function is symmetric about the origin.

Absolute Value

  • Absolute value is an even symmetric function.

Section 1.3: Trigonometric Functions

Trig Functions

  • Trig functions are used to model things that have repetitive or cyclical motion, such as sound waves, vibrations and alternating electrical currents.
  • It's often more convenient to use radians when we work with trig functions because they are related to the unit circle, a circle with radius 1.
  • Convert degrees and radians using ratio of pi = 180degrees.

The 6 Basic Trig Functions

  • Trig functions are used to relate angles to their corresponding points on a circle. Trig functions are also used to defined the relationship between the sides and angles of a triangle.
  • To define any trig action, first look at the unit circle centered at the origin. Consider the point p = (x, y) on the unit circle, and let theta be an angle with an initial side on the positive x-axis and with a terminal side that is the line segment connecting the origin O to P.
  • An angle in this position is said to 5 in standard position.

Unit Circle

  • Positive angles move counterclockwise from the positive x-axis, negative angles move clockwise.
  • Sin is y coordinate
  • Cos is x coordinate
  • On the unit circle, the tangent represents the slope of the ray that is theta radians counterclockwise of the positive x-axis.
  • An opposite slope means that the slope is equally steep, but has the opposite sign.
  • On the unit circle, the cosine represents the x-coordinate where the ray that is theta radians counterclockwise of the positive x-axis intersects the unit circle.

Section 1.4: Inverse Functions

  • The inverse function f(-1) reverses what the function did, so that the output value (from the range) gets sent back to the corresponding input value (from the domain).

f(x) = y then f-1(y) = x

  • For a function to have an inverse, it must be a one-to-one function.

Strategy for Finding an Inverse Function

  1. Solve the equation y = f(x) for x.
  1. Interchange the variables x and y, then write y = f1(x).

Inverse Trigonometric Functions

  • The 6 basic trig functions (sine, cos, tan, csec, sec, cot) are periodic, therefore they are not one-to-one. Their graphs all fail the horizontal line test. However, if we restrict the domain of a trig function to an interval where it is one-to-one, we can define its inverse.
  • The convention is to restrict the domain of sine to [-pi//2, pi/2] and cosine to [0, pi]. For both, the range is [-1. 1] is maintained.
  • For the tangent function, the convention is to restrict the domain to include all values between vertical asymptotes. (-pi/2, pi/2]
  • The principal value of an inverse trigonometric function is the main angle (or the default output) that the function gives. It’s the angle that lies within a restricted range so that the inverse function can be well-defined and single-valued (i.e., give only one answer).

Section 2.1: A Preview of Calculus

The Tangent Problem and Differential Calculus

We can approximate the rate of change of a function f(x) at a point (a, f(a)) on its graph by taking another point (x, f(x)) on the graph of f(x), drawing a line through the two points and calculating the slope of the resulting line. This is the secant line.

The secant to the function f(x) through the points (a, f(a)) and (x, f(x)) is the line passing through those points. Its slope is given by:

msec = f(x) = f(a) / x-a

The accuracy of approximating the rate of change of the function with a secant line depends on how close x is to a.

In the figure below, you can see that as we choose points (x, f(x)) that get closer and closer to (a, f(a)), the secant lines approach a special line called the tangent line to the graph at the point (a, f(a)).

The slope of the tangent line to the graph of a function f(x) at a point (a, f(a)) measures the rate of change of the function at x = a. This value also represents the derivative (also called the rate of change) of the function at x = a, denoted by f'(a) (read as: "f prime of a")

Differential calculus is the field of calculus related to the study of derivatives and their applications to areas such as economics, engineering, and the natural sciences.

Section 2.4: Continuity

Continuity

A function is continuous at a point if:

  • f(a) is defined - plug a into the function
  • lim f(x) exists - use one-sided limit
x -> a
  • lim f(x) = f(a) - top 2 answers should match
x -> a

A function is discontinuous at a point if it doesn't meet these conditions.

Discontinuity

There are 3 common categories of discontinuities.

  • a removable discontinuity - a hole in the graph
  • a jump discontinuity - sides of function do not line up
  • an infinite discontinuity - vertical asymptote

Section 3.1: Defining the Derivative

Limits:

A limit, in the context of calculus, is the value that a function approaches as the input (usually denoted by 'x') approaches a certain point (usually denoted by 'a'). It's about what a function "gets close to" rather than necessarily what it equals at that specific point. For example, the limit of the function f(x) = 2x as x approaches 2 is 4.

Derivatives:

The derivative of a function, denoted as f'(x) or dy/dx, measures the instantaneous rate of change of the function at a particular point. It can also be interpreted as the slope of the tangent line to the curve of the function at that point. The derivative is found by calculating a specific type of limit, specifically the limit of a difference quotient.

Tangent and Secant Lines

Tangent line - The tangent line is the line that touches the curve at a point.

Secant line - Recall that we used the slope of a secant line to a function at a point (a, f(a)) to estimate the rate of change, or the rate at which on variable changes in relation to another variable.

Example: Find tangent line slope to the graph of f(x) = sqrt(x) at x = 4.

Derivative of a Function at a Point

The type of limit we compute in order to find the slope of the tangent line to a function at a point occurs in many applications, The limit occurs so frequently we give this value a special name: the derivative. The process of finding a derivative is called differentiation.

Example - For f(x) = x^2 + 3x + 2, find f'(1).

Derivative Functions

The derivative function gives the derivative of a function at each point in the domain of the original function for which the derivative is defined.

A function f(x) is said to be differentiable at a point if f'(a) exists. More generally, a function is said to be differentiable on S if it is differentiable at every point in an open set S, and a differentiable function is one in which f'(x) exists on its domain.

In general, for the function y = f(x), we have the following notations to represent its derivative.

f'(x), y', dy/dx, d/dx(f(x)
